fix-the-page.chrome-extension.sgit.ai / privacy

Privacy

The short version: nothing leaves your browser. The extension makes no network calls, sends no telemetry, has no account, and reads from a page only the two things a title fix needs. Here is the long version, with where to check each claim.

No network calls

  • The extension's pages run under a Content Security Policy with connect-src 'none', which the browser enforces: they cannot open a connection to anything.
  • The code contains no fetch, XMLHttpRequest, WebSocket, sendBeacon or EventSource. The validator checks for each of them on every build and refuses a release that has one. The test suite checks that the validator catches them.
  • No script or stylesheet is loaded from the web. Every file the extension runs is in the package you installed, and you can read it.

No telemetry, no analytics, no account

The extension does not count, report or phone home about anything. It cannot: see above. This website is static, served from GitHub Pages, with no analytics script.

Nothing is stored about the pages you visit. A rule names a pattern you chose, not a history.

What it reads from a page

Two things: the page's URL, to decide whether a rule matches, and the page's title, to replace it or build on it. It never reads form fields, cookies, page text or anything else, and never stores what it reads. The engine runs in Chrome's isolated world for content scripts, so the page's own scripts cannot see the extension and the extension does not share the page's JavaScript objects. The one exception is a tiny bridge, run in the page's world only when you open the popup there, which looks for a site's published page API at window.__tools.page and records its name, version and the names of its fixes, nothing more, on an attribute the engine reads.

Export and import

Export writes your rules to a JSON file through your browser's download, to a place you choose. Import reads a file you pick. Neither touches the network. An import file is validated against the documented shape and refused whole if it does not match; nothing in it is executed under any circumstances.

This website

Static pages on GitHub Pages, no cookies set by us, no analytics, no forms. GitHub serves the pages and keeps its own server logs under its privacy statement.

Questions

The source is public at GitHub. If you find anything here that does not match the code, that is a bug in one or the other, and the repository's issues are the place for it.
