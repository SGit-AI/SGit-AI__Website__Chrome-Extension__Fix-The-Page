Release history

Every push to dev is a release: CI validates the site and the extension, runs the tests, verifies the version bump, tags the commit vX.Y.Z, and deploys to GitHub Pages. The version is owned by admin/build/version.txt, must agree with the release commit's subject, and is the extension's version too, without the v. So "which build am I running?" always has one answer.

VersionDateWhat shipped
v0.3.0 25 October 2026 The playground beside the page, and the domain. The extension: the playground is now the extension's side panel (sidePanel permission, side_panel.default_path), opened from a button in the popup or a context menu item, and it follows the active tab it is allowed to see: a tab the icon was clicked on, or a site allowed with "Always on this site"; otherwise it says so. "Open in a tab" keeps the old form. Undo reaches the tab a run was on even after switching. The popup shows the version and offers the panel first, as the family's recorder popup does. The domain: fix-the-page.chrome-extension.sgit.ai, singular, as Dinis set it up; the CNAME, every canonical URL, the manifest and the twins changed with it. The validator: sidePanel allowed, side_panel.default_path checked. The tests: panel mode following the active tab, the popup's panel button; 216 in all.
v0.2.0 25 October 2026 The playground and Script Behaviour Policies. The extension: a playground page where a fix is written as a script and run on the tab the popup was opened on; a Script Behaviour Policy per script (a list of capabilities and limits), a static review that compares what the script calls with what the policy grants and refuses banned names, and a runtime gate that checks every capability call against the policy before it reaches the page; a sandbox page (Chrome's sandbox manifest key, an opaque origin, a CSP with connect-src 'none') in which the script sees nothing but page and log; eight reversible capabilities in the engine (title.get, title.set, url.get, dom.count, dom.text, dom.hide, dom.setText, css.add) with an effects log per run and Undo; saved experiments in chrome.storage.local, generic or site-specific by their match pattern, with export, import and copy as JSON; seven starter examples. The validator: comments and strings are blanked before the code bans run; new Function is allowed in sandbox.js alone; an <iframe> may only point at a declared sandbox page; the sandbox CSP must set connect-src 'none' and allow nothing but scripts. The tests: 45 tests of the policy core, 13 more engine-in-a-page tests (capabilities, undo, the sandbox realm under its CSP including the escape that gains nothing), 5 playground tests in Chromium; 214 in all. The site: the article Script Behaviour Policies with the mapping from Agent and Process Behaviour Policies; the plan to split the extension from the site and start a library of fixes; the playground page; navigation.
v0.1.0 24 October 2026 First MVP, built from the briefing pack. The extension: Manifest V3 with activeTab, scripting, storage and contextMenus, optional host permissions for http and https, a CSP with connect-src 'none'; the title fix with set, prefix, suffix and template modes; on-demand apply through activeTab; persistent per-site rules through optional_host_permissions and registerContentScripts; an engine that holds the title against rewrites and route changes, undoes, and is idempotent; the popup with preview, pattern, "Always on this site", Undo and the restricted-page message; "My rules" with edit, enable, delete, export, import, site access removal and the build stamp; the keyboard shortcut and the context menu item; detection of a site's page API. The release: releases/fix-the-page-v0.3.0.zip and its SHA-256, built deterministically by package.mjs. The tests: 97 unit tests of the engine's core, 11 engine-in-a-page tests and 12 extension-in-Chromium tests with Playwright, 31 validator tests, and a runner that fails if a test file is not run. The site: this page, the front page, install (from a clone or from the zip, with screenshots), the title fix, permissions with Chrome's documentation quoted, privacy, source and releases, markdown twins, llms.txt, and the validate → test → tag → deploy pipeline copied from the hub with a test job added.

fix-the-page.chrome-extension.sgit.ai

A Chrome extension that fixes the page you are on, only when you ask, and can say exactly what it changed. One generic extension, built on activeTab, starting with the tab's title. Code Apache 2.0; content CC BY 4.0.

Published by the sgit project. The extension makes no network calls and sends nothing anywhere; this site is static and has no analytics.
